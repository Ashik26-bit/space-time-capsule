SPACE TIME CAPSULE — THE LUNAR-TICS
A beginner-friendly static website prototype.

HOW TO OPEN
1. Extract the ZIP file.
2. Open the extracted folder.
3. Double-click index.html. It should open in your browser.
4. Internet connection is needed for the Google Fonts used in the design; the website itself runs locally.

FILES
- index.html: page content
- style.css: colours, layout and responsive design
- script.js: navigation, mission filters and quiz

WHAT WORKS
- Responsive homepage and destination sections
- Mission cards with NASA source links
- Moon / Mars / Deep Space filters
- Interactive three-question quiz
- Timeline and navigation

IMPORTANT BEFORE NASA SUBMISSION
- This is a starter prototype, not a NASA product.
- Check all mission status information against current NASA pages before submitting.
- Add your six team members' names if required.
- Add real NASA images only after checking each image's page and credit line. Do not assume all NASA-hosted media has identical usage rights.
- Take screenshots of the actual running website for your presentation.
- Do not claim features are implemented unless you test them.

PUBLISHING
This is a static website and does not need Flask or a server. You can publish it using GitHub Pages:
https://docs.github.com/en/pages/quickstart
